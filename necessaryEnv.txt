add a .env file at ./backend with these vars:

server port
SERVER_PORT=3000

allowed url to send requests to the api
CORS_ALLOWED_URL='http://localhost:5000'

mongoDB connection string
DATABASE_CONNECTION_STRING=''

json web token secret and expiration
TOKEN_SECRET=''
TOKEN_EXPIRATION=7d

email account for sending emails (forget password funcionality)
GOOGLE_APP_EMAIL=''
email password
GOOGLE_APP_PASSWORD=''
